# 游民活点地图 · Nomad's Map

数字游民互助任务地图，哈利波特「活点地图」风格：羊皮纸、墨迹脚印、咒语开场。

- 发布者 30 秒钉一条远程可完成的小求助（修 Bug / 翻译 / 设计 / 数据脚本）
- 找活的人按学院筛选，点脚印看详情，**一键显示联系方式**，对接在微信里完成
- **平台不碰钱、不托管、不做聊天**——用完即走的工具，对接归生活
- 数据存浏览器 localStorage（本机版）；共享版可平滑切换到云端表

## 运行与地图 Key

页面用腾讯地图 GL JS（合规底图）。两种模式：

- **WorkBuddy 内预览**：零配置，代理模式自动生效
- **独立部署（GitHub Pages / 自有域名）**：在 [腾讯位置服务](https://lbs.qq.com/) 免费申请一个 Web JS API key，打开 `index.html` 把顶部 `const TMAP_KEY = ''` 填上即可；建议同时在该 key 的设置里配 Referer 白名单
